1. Repository herunterladen:

Klicke oben rechts im GitHub-Repository auf den grünen Button "Code".
Wähle "Download ZIP", um den gesamten Ordner als ZIP-Datei herunterzuladen.

2. Extrahieren:

Entpacke die heruntergeladene ZIP-Datei an einen beliebigen Ort auf deinem Computer.

3. Nach dem Entpacken findest du folgende Ordnerstruktur vor:   

📂 HMI/: Enthält die WinCC OA Visualisierung und Panels (SCADA-Schnittstelle).   
📂 HW Dokumentation/: Enthält die technische Hardware-Dokumentation (z. B. Belegungspläne und Gerätespezifikationen).   
📂 Netzwerk/: Enthält die Netzwerkarchitektur, Topologiepläne sowie Konfigurationen für Modbus TCP und OPC UA Kommunikation.   
📂 PLC/: Enthält das komplette TwinCAT 3 SPS-Projekt (SCL/ST-Logik, Bausteine und globale Variablenlisten).   
📂 Zertifikate/: Enthält Zertifikate und Sicherheitskonfigurationen (z. B. für die verschlüsselte OPC UA Verbindung).
